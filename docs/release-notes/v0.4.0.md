# GitHub PR Explorer — Release Notes v0.4.0

**April 16, 2026** · covers March 30 – April 16

## Highlights

- **Repo Stats tab.** Overview cards, language bar, file-extension breakdown,
  and lines of code. LOC is computed from a `gh repo clone` so private repos
  work; it recalculates on demand and shows when it was last computed.
  Vendored directories are excluded from file counts.
- **Clickable Changes Requested badge.** Opens a modal listing each
  reviewer's comments so you can see what was asked for without leaving the
  list.
- **Verdict preview.** See the composed body before you post. The review
  summary is now a toggleable section in the composer.
- **Review failures are actionable.** The failure modal explains common causes
  and has a Retry button.
- **Description and Changes Requested modals** are draggable and resizable.
- **Previously resolved issues** now show correctly in the verdict preview.
