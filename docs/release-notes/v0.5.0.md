# GitHub PR Explorer — Release Notes v0.5.0

**April 21, 2026** · covers April 16 – 21

## Highlights

- **PR Timelines.** A Timeline button on PR cards and merge queue items opens a
  full-screen, animated event feed for one PR: commits, reviews, comments,
  labels, state changes, and more. Filter by event type with chips, refresh on
  demand, and it keeps polling while open. Cached with a state-aware TTL so
  merged PRs are not refetched.
- **Inline-issues summary table.** When a verdict is posted with inline
  comments, the body starts with a table of severity, title and location so
  the GitHub review entry indexes the line comments instead of looking empty.
- **Approved-by-you highlight.** PRs you have already approved get a
  neon-green tint in the list and the queue.
- Review summaries are saved verbatim instead of being re-rendered.
