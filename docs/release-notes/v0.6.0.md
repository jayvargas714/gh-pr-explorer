# GitHub PR Explorer — Release Notes v0.6.0

**June 3, 2026** · covers April 27 – June 3

## Highlights

### Swimlane board (Kanban)

The merge queue gets a Trello-style board. Same PRs, arranged in lanes you
define (waiting on author, ready to verdict, blocked, whatever fits).

- Create, rename, recolor and reorder lanes. Drag cards between lanes or use
  the per-card lane dropdown.
- **Pin** important cards to the top of their lane.
- **Search** the board and **filter by badge** (state, draft, review status,
  CI, score bucket, new commits, follow-up) with AND/OR modes. Matches glow,
  non-matches dim.
- **Clear merged** removes every merged card in one click (pinned cards stay).
- The board stays live: it polls every 45 seconds while open and shows an
  "Updated X ago" indicator.

### Choose your reviewer

A picker next to the Review button selects the agent: the default code
reviewer, the **Product Brief reviewer**, or the new **Engineering Design
reviewer**. All three produce the same review format, so verdicts, inline
comments and history work identically.

### Better card tools

- **View Description** on queue and board cards, same as the PR list.
- Verdict sections open in a floating editor, and the preview itself is
  editable with a "manually edited" badge.
- Hover **CI Failed** to see which checks failed.
- The "New Commits" badge no longer goes dark when a head SHA was missed.

## Also

- Review paths are config-driven (`reviews_dir`, default `~/code-reviews`) so
  the app runs on any machine without edits.
- Merge queue loads at startup so PR-list queue buttons are correct immediately.
- Timeline: empty-body events dropped; comment and review dots use distinct
  colors.
