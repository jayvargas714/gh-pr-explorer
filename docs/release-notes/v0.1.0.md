# GitHub PR Explorer — Release Notes v0.1.0

**February 7, 2026** · covers January 30 – February 7

The first working version of the tool: a Flask backend that talks to GitHub
through the `gh` CLI, a Vue.js single-page UI, and a local SQLite database.

## What you get

- **Browse PRs across your accounts and orgs.** Pick an account, pick a repo,
  and filter PRs across five tabs (Basic, Review, People, Dates, Advanced).
- **Status badges on every card.** Review state (Approved / Changes Requested /
  Review Required) and CI state (passed / failed / running / skipped).
- **Claude code reviews from the app.** Start a review on a PR, watch it run,
  read the result in a markdown viewer, and copy it out. Follow-up reviews
  carry the previous review as context.
- **Review History.** Every completed review is stored in SQLite with a 0–10
  score badge. Search by repo or author.
- **Post critical issues as inline comments** straight to the PR, from the PR
  list or the merge queue.
- **Merge queue.** A persistent, ordered list of PRs you intend to merge, with
  per-item notes, review score, and a "New Commits since review" badge.
- **Developer Stats and Analytics.** Contribution metrics, PR lifecycle times,
  code activity, and reviewer responsiveness, cached for four hours with
  background refresh. All table columns sort and have tooltips.
- **CI/Workflows tab.** Up to 300 recent workflow runs with sorting and paging.
- **Your settings survive a refresh.** Filters, account, and repo selection are
  saved to the database and restored on load.
- **Dark and light theme.**
