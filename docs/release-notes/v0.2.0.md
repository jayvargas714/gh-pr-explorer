# GitHub PR Explorer — Release Notes v0.2.0

**February 9, 2026** · covers February 7 – 9

The frontend was rewritten from scratch in **React 18 + TypeScript** with Vite
and the Matrix UI design system. The Vue.js app is gone. Every feature from
v0.1.0 carried over, and the app is now faster and easier to extend.

## Highlights

- **New React UI.** Same tabs and workflows, new component library, typed API
  layer, and per-feature state stores. Dark and light themes rebuilt on Matrix
  design tokens.
- **Filter dropdowns are live.** Contributors, labels, branches, milestones and
  teams load from the selected repo instead of being empty placeholders.
- **Analytics charts fixed and explained.** Bar, stacked and grouped charts no
  longer overflow, and each chart has an info tooltip. Per-contributor time
  series and a top-5 activity view are new.
- **CI/Workflows tab fixes.** Pagination works, the pass rate is a real
  percentage, page size is selectable (25/50/100), and an all-time run total
  shows alongside the fetched window.
- **Faster merge queue.** PRs are fetched in parallel and the UI updates
  optimistically when you add, remove or reorder.
- **Instant tooltips** on column headers and badges.
- **Caching in SQLite.** Workflow runs and code-activity data are cached with
  stale-while-revalidate and a manual refresh button.
- **Better inline comments.** Posts the full issue text and renders
  GitHub-flavored markdown in the viewer.
- **One `config.json`.** Backend and frontend read host and port from the same
  file. The app can be served on your LAN (`0.0.0.0`) rather than localhost
  only; see `CONFIGURATION.md`.

## Upgrade notes

Run `cd frontend && npm install && npm run build` once. Flask serves the built
app from `frontend/dist/`.
