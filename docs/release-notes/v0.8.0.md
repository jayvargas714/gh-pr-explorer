# GitHub PR Explorer — Release Notes v0.8.0

**August 28, 2026** · covers August 11 – 28

This release lets a review close its own loop: arm a PR and a completed Claude
review decides the verdict, posts it, and re-reviews when the author pushes.
It also adds the Review Logs tab so you can see what the machine did.

## Highlights

### 🤖 Auto verdicts

Arm a queue or board card with the **🤖 Auto** toggle.

- A completed review's issue counts are compared to thresholds (default
  0 critical / 0 major / 99 minor). Over any limit posts **Changes Requested**;
  within all of them posts **Approve** only if auto-approve is on, otherwise
  the pass is recorded and nothing is posted. Both switches default off.
- **Comment mode** posts every review's findings as a plain comment. This is
  also the working path for your own PRs, which GitHub will not let you
  approve.
- **Per-PR criteria overrides.** Any armed PR can carry its own thresholds.
- Every auto verdict is badged in the UI and recorded with the criteria that
  drove it.

### Auto follow-up reviews

With the follow-up toggle on, armed PRs are re-reviewed automatically when new
commits land. First reviews stay manual.

### Review Logs tab

Every review attempt is recorded as lifecycle events (started, retried,
completed, failed, gave up, cancelled, verdict posted or not).

- Runs are grouped by day with per-day outcome counts, one day per page, with
  a day navigator and calendar jump.
- Hover a run for issue counts and timing.
- Retention is configurable.

### Reviews announce themselves

A "Code review in progress" comment is posted on the PR when a review starts
(flag: `post_review_started_comment`). Auto-started reviews carry a persistent
indicator.

## Also

- **Faster PR list.** PRs are served from a locally synced store that
  backfills on first visit and re-hydrates only changed PRs. Per-card refresh
  and a freshness stamp. `pr_sync` config block with a kill switch.
- **No more 0/10 stubs.** A review that exits without writing output is
  treated as failed and retried (default 3 attempts).
- Reviews and audits are pinned to Claude Opus 5 for reproducible scores.
- Swimlane header shows `🤖 N auto · M manual` with an All / Auto / Manual
  filter. Arming is instant.
