# GitHub PR Explorer — Release Notes v0.7.0

**June 13, 2026** · covers June 5 – 13

## Highlights

### PB ↔ ED audits

A second kind of review. An **audit** checks an Engineering Design against its
parent Product Brief and against sibling EDs, and reports findings with
blocking status rather than a score.

- Its own **Audit** button next to Review, so a review and an audit can run on
  the same PR at the same time.
- **AuditViewer** modal, audit chips on cards, and an **Audits** tab in the
  history panel. Failed audits are marked distinctly.
- **Verdict source toggle.** When a PR has both a review and an audit, the
  verdict composer lets you choose which one to compose from.
- Post audit findings as inline comments, from the viewer or the composer.

### Rev log badge

Hover **rev log (N)** on a queue or board card to see every review and audit
ever run on that PR, newest first, with score or finding counts, the reviewer
agent used, and local timestamps. Click a row to open it.
